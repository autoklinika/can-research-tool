# Materiały referencyjne

Ten katalog przechowuje sprawdzone przykłady techniczne używane do poznania Kvaser CANlib i zachowania stanowiska.

Kod umieszczony tutaj:

- nie jest kodem bazowym aplikacji docelowej,
- nie powinien być przenoszony bezpośrednio do `src/`,
- musi zawierać opis środowiska i sposobu weryfikacji,
- może służyć jako test porównawczy dla nowej implementacji.

Działający skrypt użytkownika należy dodać wraz z krótkim plikiem opisującym model Kvasera, system Windows, wersję Pythona, wersję sterowników/CANlib, bitrate oraz potwierdzone funkcje RX i TX.
