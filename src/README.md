# Kod aplikacji

Docelowe moduły:

- `transport/` — abstrakcja CAN i adapter Kvaser CANlib,
- `capture/` — odbiór, timestampy i zapis,
- `transmit/` — kontrolowane nadawanie,
- `sessions/` — metadane, zdarzenia i integralność danych,
- `analysis/` — analiza ramek i porównywanie sesji,
- `common/` — modele danych, konfiguracja i błędy.

Kod źródłowy zostanie dodany po analizie działającego skryptu referencyjnego i zatwierdzeniu interfejsów pierwszej wersji.
